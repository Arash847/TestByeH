Declare KERNEL_ADDRESS_DMAP_BASE ourselves

It is not in the SDK public ps5/kernel.h but is a global in the SDK
runtime that __kernel_init fills in via kernel_find_dmap_base(), so
declaring it lets us link against the same value __kernel_init computed
instead of re-deriving it. Falls back to the hand-computed pml4 - cr3 if
it is zero.
